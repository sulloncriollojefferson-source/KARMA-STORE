# KARMA — tienda de ropa

Proyecto inicial para desarrollar la tienda online de KARMA con HTML, CSS y JavaScript.

## Estructura

- `index.html` → estructura de la página
- `styles.css` → diseño visual
- `script.js` → productos y carrito
- `assets/` → coloca aquí las fotos de tus camisetas

## Abrir en VS Code

1. Descomprime el proyecto.
2. Abre la carpeta en Visual Studio Code.
3. Instala la extensión **Live Server**.
4. Abre `index.html`.
5. Clic derecho → **Open with Live Server**.

## Para colocar tus diseños

En `script.js` puedes cambiar los productos.
Después podemos conectar las imágenes reales de cada camiseta desde `assets/`.
